# SpeedFast App - Sistema de Asignación de Pedidos

## Descripción
Actividad formativa de la semana 1. Este proyecto es un prototipo en Java para la empresa de reparto a domicilio "SpeedFast". El sistema simula la asignación de repartidores dependiendo del tipo de pedido (Comida, Encomienda o Compra Express).

## Conceptos Aplicados
- Programación Orientada a Objetos (POO).
- **Herencia:** Creación de una clase base `Pedido` y tres subclases especializadas.
- **Polimorfismo:** 
  - *Sobreescritura (Override):* Lógica específica de asignación según el tipo de pedido.
  - *Sobrecarga (Overload):* Métodos con el mismo nombre pero diferente firma (con y sin parámetro del nombre del repartidor).

## Ejecución
El proyecto fue desarrollado en IntelliJ IDEA. Para probar su funcionamiento, ejecute la clase `Main.java` ubicada en la carpeta `src`.
